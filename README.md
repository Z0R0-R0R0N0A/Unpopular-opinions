**Unpopular Opinion** is an anonymous social website where people can post opinions they normally wouldn't say publicly.

Users can:

* Post opinions anonymously
* Vote **“Based” 👍** or **“L + Ratio” 👎**
* See the most popular and controversial opinions
* Search and filter opinions by **Hot, New, Top, and Controversial**
* View trending opinions

The main idea is to create a **fun, debate-driven platform where people can freely share and judge unpopular opinions**.
